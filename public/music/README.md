# Background music

Add these files:

- `soft-instrumental.mp3` (plays on the main journey, looped)
- `last-song.mp3` (auto-switches on the "One Last Thing" video step, looped)

Behavior:

- Music starts after first interaction.
- On the video step, soft instrumental stops and `last-song.mp3` starts.
- The top-right toggle controls the currently active track.
